# LumaFlow

## Ziel

LumaFlow ist eine moderne webbasierte Projekt- und Meetingmanagement-Anwendung.

Ziel ist es, Projektmanagement, Meetings, Dokumente, Aufgaben und Termine in einer übersichtlichen Oberfläche zusammenzuführen.

## Technologien

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Font Awesome
- LocalStorage
